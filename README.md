# Smart-Spam-Detection-Platform-Based-on-ML-Models
This project develops an intelligent email spam detection platform using Machine Learning. EDA and NLP preprocessing were applied to email text, followed by stemming and TF-IDF vectorization. Seven classification algorithms were trained and compared. The selected model enables fast, reliable, and automated spam detection.
LINK to the dataset used in this platform : https://www.kaggle.com/datasets/shantanudhakadd/email-spam-detection-dataset-classification
